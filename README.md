
# Enterprise React Admin Dashboard

Production-style Admin Dashboard built with **React 18**, **TypeScript**, **React Query**, **Tailwind CSS**, and **monorepo-style architecture**.

## Features
- Authentication context (mock JWT)
- Protected routes
- Dashboard KPIs
- Charts & tables
- API layer with Axios
- Dark mode toggle
- Clean, scalable structure

## Run
```bash
npm install
npm run dev
```
